# Qadet Desktop downloads

This repository holds only the installers for Qadet Desktop, published as GitHub Releases.
The app's source is private.

Download the latest version from the Qadet download page, or from **Releases** here:

- macOS: Apple Silicon and Intel (`.dmg`)
- Windows 10 and 11, 64-bit (`.msi`)
- Linux x64 (`.AppImage`, `.deb`)
